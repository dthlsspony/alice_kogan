# Kogan (kogan_new)
Копия кодовой базы «Алисы» (../viilma) под будущий сайт kogan-im.com — план переноса в docs/www-план-переноса.md. Код пока идентичен, отличается только окружение (порт 8091, БД kogan, контейнеры kogan_*).

Коллекция цитат с полнотекстовым поиском, комментариями, статьями и настраиваемым меню.

## Стек

- **PHP 8.4** + Laravel 13
- **MariaDB 11.4** — хранение данных и полнотекстовый поиск (FULLTEXT, BOOLEAN MODE)
- **Filament 5** — административная панель
- **Tailwind CSS 4** + Vite 8 — фронтенд
- **Docker Compose** — PHP-FPM, Nginx, MariaDB

Поиск работает целиком средствами MariaDB: индекс FULLTEXT по тексту цитат,
префиксный поиск (`слово*`) в BOOLEAN MODE частично компенсирует русскую
морфологию, название/автор книги ищутся LIKE-ом. Elasticsearch удалён.

## Структура

```
kogan_new/
├── docker-compose.yml      # mariadb + php + nginx, сайт на http://localhost:8091
├── Dockerfile              # PHP-FPM 8.4 (bookworm) + OPcache + composer
├── docker/php/opcache.ini
├── nginx/default.conf
└── src/                    # приложение Laravel
    ├── app/
    │   ├── Models/         # Quote, Book, Tag, TagCategory, Article, Comment, MenuItem, User
    │   ├── Services/       # QuoteSearchService (MariaDB FULLTEXT)
    │   ├── Http/Controllers/   # Frontend, Auth, Article, Quote, Comment, QuoteSearch(API)
    │   └── Filament/       # ресурсы: Books, Quotes, Tags, Articles, Comments, MenuItems
    ├── resources/views/    # Blade + Tailwind (без JS-фреймворков)
    └── database/
```

## Быстрый старт (Docker)

```bash
cd kogan_new
docker compose up -d --build          # mariadb, php, nginx
docker compose exec php composer install
cd src && npm install --ignore-scripts && npm run build && cd ..
docker compose exec php cp .env.example .env   # если .env ещё нет
docker compose exec php php artisan key:generate
docker compose exec php php artisan migrate --seed
```

Сайт: **http://localhost:8091**
Админка: **http://localhost:8091/admin** — `admin@example.com` / `admin123`
(сменить после первого входа; seeder: `AdminUserSeeder`).

## Команды

| Команда (внутри `docker compose exec php`) | Описание |
|---|---|
| `php artisan test` | Тесты (Pest, SQLite in-memory) |
| `php artisan migrate --seed` | Миграции + демо-данные (включая иллюстрации) |
| `php artisan illustrations:generate` | SVG-обложки книг, баннеры статей, фигуры, плейсхолдеры |
| `./vendor/bin/pint --dirty` | Авто-стиль кода |

Сборка ассетов: `cd src && npm run build` (node — на хосте). После добавления
новых Tailwind-классов в blade-шаблонах не забудьте пересобрать ассеты.

## Возможности

- **Универсальный поиск** (`/search`, API `GET /api/quotes?query=&types[]=&tags[]=`)
  по **цитатам, книгам, статьям и страницам** с фильтром по типам контента
  (множественный выбор), релевантностью, фильтром цитат по тегам и объединённой
  пагинацией. MariaDB FULLTEXT + префиксный матчинг русских словоформ.
- **Регистрация и вход** обычных пользователей на сайте (`/register`, `/login`),
  роли: обычной пользатель / администратор (`users.is_admin`). В админку пускает
  только админ (контракт `FilamentUser` + middleware `EnsureUserIsAdmin`).
- **Комментарии** к цитатам, книгам, статьям и страницам (polymorphic). Пишут
  только авторизованные; комментарий попадает в статус *на проверке* и
  публикуется после одобрения в админке.
- **Статьи** (`/articles`): создаёт админ в Filament, публикация флагом + датой,
  автослаг с транслитерацией.
- **Статические страницы**: создаются и редактируются в админке (ресурс
  «Страницы»), произвольные в т.ч. вложенные адреса (`about/author`); рендерятся
  через fallback-роут. Базовые «Об авторе»/«О проекте» — в сеялке.
- **Настраиваемое меню** (ресурс «Меню сайта»): пункты с вложенностью до 2 уровней,
  порядок, видимость, target; рендерится в шапке с выпадающими подпунктами.
- **Обложки и иллюстрации**: у книг и статей есть `image_path` — обложка/баннер.
  Вьюхи показывают загруженную картинку, при её отсутствии — плейсхолдер.
  Команда `illustrations:generate` детерминированно рисует SVG-обложки
  (градиент + узоры + типографика), баннеры статей и декоративные фигуры
  (`articles/figures/*.svg`) для вставки в текст. В Filament обложку можно
  загрузить вручную (FileUpload, диск `public`). Запуск `php artisan storage:link`
  обязателен.
- **Вид списков**: на страницах книг и статей — переключатель
  «карточки / список» (параметр `?view=grid|list`).

## Админ-панель

Группы навигации: **Контент** (Books, Quotes, Tags, Tag Categories),
**Публикации** (Статьи, Комментарии), **Сайт** (Меню сайта, Страницы, Пользователи).

Раздел `/admin` скрыт полностью: гостям и обычным пользователям все его
маршруты отдают **404** (не редирект и не 403). Отдельной формы входа в
админку нет — **вход для всех, включая администраторов, через общую форму
сайта** (`/login`); `/admin/login` и `/admin/password-reset` не существуют (404).
После входа администратор попадает сразу в панель, остальные — на главную.
Пункт «Админка» в шапке сайта показывается только администраторам.

Управление пользователями (ресурс «Пользователи»): создание, редактирование,
пароль (при редактировании оставьте пустым, чтобы не менять), флаг
«Администратор», фильтр по роли, защита от удаления собственной учётной записи.

## Контент Когана (импорт из старого сайта)

Контент kogan-im.com перенесён в БД и сидер (см. `docs/www-план-переноса.md`,
этап 2). Пайплайн двухшаговый:

1. `docker compose exec php php artisan kogan:import` — парсит рабочую копию
   старого сайта (`../legacy`, маунтится как `/var/www/legacy`): cp1251 → UTF-8,
   резка по маркерам `boxbefore/boxafter`, чистка URL старого хоста, файлы →
   `storage/app/public/kogan/…`, ссылки на старые страницы → новые адреса.
   Результат — дамп `src/database/seeders/data/kogan/*.json` (в git).
2. `KoganContentSeeder` (вызывается из `DatabaseSeeder`) — читает дамп,
   создаёт страницы/статьи/книги, восстанавливает файлы в storage (если их
   нет — берёт из `/var/www/legacy`), строит меню.

Полная пересборка с нуля: `docker compose exec php php artisan migrate:fresh --seed`.
Админка: `http://localhost:8091/admin` (вход `admin@example.com` / `admin123`).

Не перенесено: видео .wmv (нужен ffmpeg → mp4), привязка фото mcGallery
`albums/1` к статье семинара 2008, вычитка главной. Битые ссылки старого
сайта перечислены в `src/database/seeders/data/kogan/broken.json`.

## Дизайн — в стиле старого сайта (2026-10-30)

Фронтенд kogan_new оформлен под kogan-im.com: бежевый фон `#F3E7AF`, белый
«бокс» контента с золотой окантовкой (#CA924F, картинки шаблона в
`public/images/kogan/`), Times New Roman, шапка «Сайт посвящён И. М. Когану…»,
верхнее меню с ромбиками-разделителями и активным пунктом (голубой `#e3e5ff`),
левое подменю раздела, хлебные крошки, красные заголовки `#A10F06`.

Сделано:
- `resources/css/app.css` — старый `style.css` целиком + каркас `.k-*`;
  dark-вариант Tailwind отключён (`@custom-variant dark`), чтобы тёмная тема
  ОС не ломала вид.
- `layouts/app.blade.php` — шапка/меню/сайдбар/крошки/бокс/футер в старом духе.
- `articles/index`, `articles/show`, `pages/show` — переписаны (список с датами,
  «⇐ Назад к статьям», легаси-заголовок `p.header` не дублируется).
- Картинки шаблона старого сайта — `public/images/kogan/` (17 шт).

Не тронуто: главная (`/`, пока вьюха «Алисы» в светлом виде), поиск, книги,
блок комментариев (светлые Tailwind-карточки внутри бокса).

Вёрстка каркаса — **mobile-first** (2026-10-30): база CSS — мобильный вид
(меню-«чипы» в несколько строк, подменю горизонтальной лентой, узкие рейки
рамки, текст без выключки), двухколоночный десктоп в духе старого сайта —
через `@media (min-width: 821px)`. Легаси-таблицы в контенте резиновые
(`display:block; overflow-x:auto`), картинки — `max-width:100%`.

## Современный апдейт (2026-10-30): меню, шрифты, SEO, дашборд

- **Мобильное меню**: гамбургер (кнопка справа вверху, `.k-burger`), панель
  с пунктами — чипы с активной подсветкой; закрывается кликом мимо. На
  десктопе — прежняя строка меню с ромбиками.
- **Шрифты**: PT Sans (обвязка: заголовок, меню, крошки, сайдбар) +
  PT Serif (текст контента), self-hosted через `@fontsource/pt-*`
  (кириллица в комплекте).
- **SEO**: у статей и страниц поля `seo_title` и `meta_description`
  (таб «SEO» в админке), на фронте рендерятся `<title>`, meta description,
  canonical и Open Graph (og:image — из иллюстрации). Пустые поля —
  фолбэк на заголовок/краткое описание (сервис `App\Services\Seo`).
- **Дашборд админки** («Инфопанель»): посещения сегодня/7/30 дней, пользователи
  (и новые за 30 дней), комментарии (в т.ч. на проверке), статьи/страницы/книги;
  график посещений за 30 дней; топ-10 страниц (просмотры + сессии);
  последние комментарии.
- **Учёт посещений**: middleware `TrackVisit` пишет таблицу `visits`
  (GET-запросы фронта; админка/API/статика/боты не считаются; повтор страницы
  в рамках сессии или IP за 30 минут не дублируется).
- Тесты: `VisitTrackingTest`, `SeoMetaTest` (+6 кара).
